# Emmanuel Martin David — Portfolio

Personal portfolio built with [Astro](https://astro.build) and deployed on GitHub Pages.

## Tech Stack

- **Framework:** Astro 6
- **Styling:** CSS (dark theme, terminal-inspired)
- **Deploy:** GitHub Pages via GitHub Actions

## Deployment

Pushing to `main` triggers the GitHub Actions workflow (`.github/workflows/deploy.yml`) which builds and deploys automatically to GitHub Pages.

**Live site:** [emmanuelmartindavid.github.io](https://emmanuelmartindavid.github.io)
